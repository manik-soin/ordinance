About HK Compliance RAG

What is this?

HK Compliance RAG is an AI-powered knowledge base that answers questions about Hong Kong building regulations with exact clause citations. Every answer is grounded in official government codes of practice, ordinances, and practice notes.

Regulatory Sources

Codes of Practice
Fire safety, structural steel, concrete, foundations, wind effects, demolition, site supervision
Practice Notes (PNAPs)
Authorized Persons, Registered Structural Engineers, and Registered Geotechnical Engineers guidance
Legislation
Buildings Ordinance (Cap. 123), Building (Planning) Regulations (Cap. 123F), Cap. 572
Design Manuals
Barrier-free access, energy efficiency, environmental assessment, fire engineering

How It Works

The system uses a Retrieval-Augmented Generation (RAG) pipeline:

  • Ingestion — PDFs are fetched from government websites, parsed, and split into structure-aware chunks preserving Part > Section > Clause hierarchy
  • Embedding — Each chunk is embedded using OpenAI text-embedding-3-large (3072 dimensions) and stored in PostgreSQL with pgvector
  • Retrieval — Hybrid search combines vector similarity with BM25 full-text search, fused via Reciprocal Rank Fusion
  • Reranking — Top results are reranked using Cohere Rerank for precision
  • Generation — GPT-4o generates citation-grounded answers with mandatory clause references
  • Verification — Every answer is checked for phantom citations and faithfulness to source material

Safety & Quality

Every query goes through prompt injection detection, and every answer is verified for:

  • Faithfulness Score — LLM judge rates how well the answer reflects retrieved context (0-10)
  • Citation Accuracy — Percentage of cited clauses that actually appear in context
  • Phantom Citations — Citations made up by the model (flagged and counted)
  • Uncited Claims — Factual statements that should have citations but don't

Change Detection

The system periodically checks government sources for regulation updates via SHA-256 content hashing, ensuring the knowledge base stays current with the latest amendments.
